# Printed Soul — Customer Frontend

React + Vite + TypeScript + Tailwind CSS customer-facing store.

## Setup

```bash
npm install
cp .env.example .env
# VITE_API_URL mein apna backend URL daalo
```

## Run (Development)

```bash
npm run dev
```

## Build (Production)

```bash
npm run build
# dist/ folder serve karo nginx ya any static host se
```
